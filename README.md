# Ozon Product Research Tool

A lightweight browser-based tool for screening products for the Russian Ozon marketplace.

## MVP goals

- Record product name, purchase price (CNY), weight, recent sales, competitor count, estimated return risk, and Russian local-seller prevalence.
- Filter products using configurable thresholds.
- Rank candidates with a transparent heuristic score.
- Import and export CSV for batch analysis.
- Keep data in the browser by default; no external data is fabricated or fetched.

## Important

Scores are decision-support estimates based on user-entered values, not verified Ozon sales or demand data. Verify marketplace metrics and logistics costs before purchasing inventory.

## Run

Open `index.html` in a modern browser. No build step is required.
